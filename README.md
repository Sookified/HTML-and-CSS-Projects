# Academy-Cinemas
Academy Cinemas is a responsive movie theater website created using HTML, CSS, and Bootstrap. The website provides visitors with information about currently playing movies, show times, ticket selections, and contact information.

### Features
- Navigation Bar
- Now Playing Section
- Ticket Section
- Contact Section
-Footer

### Technologies Used
- HTML
- CSS
- Bootstrap
- Responsive Web Design
